## Receipt minimum

Each receipt must include source commit, workflow/run identifier, UTC time, host OS/architecture/libc, exact executable paths/hashes/versions, environment and permissions, complete fixture hash, command/API request, lifecycle timeline, stdout/stderr bytes, structured diagnostics, output-tree manifest/hashes, oracle, cleanup observation and limitations. A passing fixture certifies only that exact cell.
