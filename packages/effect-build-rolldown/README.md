# effect-build-rolldown

This package remains private until its 0.7 provider is ported. Its root exports nothing and it has no public subpaths.
The installed Rolldown dependency is 1.2.5.

Use a public provider from the [package selection guide](https://github.com/mannyc2/effect-build/blob/main/README.md).
The intended core API is described in [DESIGN.md](https://github.com/mannyc2/effect-build/blob/main/DESIGN.md).
