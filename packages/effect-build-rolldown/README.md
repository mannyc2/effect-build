# effect-build-rolldown

**Private research package. It is not a supported npm dependency.**

The package manifest is marked `private`, its root exports nothing, and there are no public `Api` or `Command`
subpaths. Do not import its source or internal files from an application.

All 19 live research operations are implemented and tested package-private. One operation is rejected. Admission
requires the package and each operation's evidence gates to close; implementation alone does not make an operation
public. The research dependency is Rolldown 1.2.5.

Use a currently public provider from the [package selection guide](https://github.com/mannyc2/effect-build/blob/main/README.md) for application build scripts.
For contributor context, see the [provider guide](https://github.com/mannyc2/effect-build/blob/main/docs/drivers.md) and the
[combined contract](https://github.com/mannyc2/effect-build/blob/main/tooling/effect-build-contract.json), which records each operation's disposition.
